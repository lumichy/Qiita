2026年8月20日、AI中継プラットフォームの **OpenRouter** に突如として正体不明のモデルが投下されました。

名前は **Ox Alpha**（オックス・アルファ）。

開発元もパラメータ規模も一切非公表の「ステルスモデル」でありながら、公開からわずか数日で **OpenRouter** の週間消費トークン数ランキング1位（17.5兆トークン）を奪取。さらにAIコーディングエージェント **OpenCode** では累計31兆トークンを消費し、利用シェア7.9%で首位に立ちました。**Cline** においても公開から48時間で推論全体の8%を占めるなど、開発者コミュニティを急速に席巻しています。

コンテキスト長100万トークン超、多段階推論（Reasoning）の可視化、画像・動画入力対応、そして何より**完全無料**。

この記事では、**Ox Alpha** の正体とうわさ、ベンチマークから見る真の実力、無料公開の背景、そして今すぐ開発で使い倒すための3つの利用ルートをまとめます。

## 2. なぜ完全無料で公開されているのか？

開発元すら名乗らない謎のモデルが、なぜこれほどの計算リソースを無償提供しているのでしょうか。

### 正式発表前の「ブラインドテスト」と負荷検証
有力とされているのが、**正式ローンチを控えた大規模なブラインドテスト**です。

過去にも LLM 開発企業がモデル名を伏せてコミュニティに無料開放し、実際の開発者によるリアルなプロンプトやコーディングタスクでの挙動・耐障害性・スケーラビリティを検証するケースがありました。

100万トークン級の推論インフラを世界中の開発者に殴らせることで、極限状態での負荷試験とフィードバック収集を一挙に行っていると考えられます。

### 正体は中国 Z.ai の「GLM-5」系か？
開発元の正体を巡っては、いくつかの決定的な検証結果が出ています。

1. **トークナイザーの一致**: 米 iSimplifyMe が自然言語のトークン分割パターン（トークナイザーの癖）を解析したところ、中国 Z.ai（Zhipu AI）の「GLM-5」系と完全に一致。
2. **APIエラーレスポンスの挙動**: セキュリティ研究者のヨセフ・カシム氏によるエラーハンドリング分析でも、GLM系配信基盤との共通点が報告されている。
3. **GLM-5.3 との類似性**: 2026年8月14日に発表された「GLM-5.3」はコンテキスト長（1M）と最大出力（128k）が一致しており、その未発表マルチモーダル版ではないかと推測されている。

一部では Google や Microsoft 説も飛び交いましたが、現状は GLM 系が最も有力な本命です。

## 3. Ox Alpha の核心能力とベンチマーク

**Ox Alpha** がここまで爆発的な支持を集めている理由は、単に無料だからというだけではありません。長時間のコーディングタスクや複雑な推論に最適化された設計にあります。

### ① 100万トークン（1M tokens）の広大な記憶領域
1,048,576 トークンのコンテキストウィンドウにより、中〜大規模リポジトリの全コードベースや数百ページの仕様書をまるごとプロンプトに投入可能です。

チャンク分割や RAG の検索漏れを気にせず、リポジトリ全体の依存関係を跨いだリファクタリングやバグ修正を依頼できます。

### ② 思考プロセスの可視化（Reasoning-first）
回答を即座に出力するのではなく、内部で仮説構築、コード検証、エッジケースの検討を多段階で行ってから最終結果を出力します。

対応するWebチャットやクライアント環境では、モデルがどう考えたのかという思考ログ（Thinking Process）がリアルタイムにストリーミング表示されるため、推論の妥当性を途中で確認できます。

### ③ マルチモーダル入力＆エージェント連携
テキストだけでなく、UIのスクリーンショットやアーキテクチャ設計図、エラー画面のキャプチャを直接読み込ませて原因分析が可能です。

また、`tools` や `tool_choice` によるネイティブな Tool Calling、`response_format` による厳格な JSON 出力に対応しており、自律型 AI エージェントのバックエンドとしてそのまま組み込めます。

### 実力値：DeepSWE ベンチマーク 58.4%
公開直後、X（旧Twitter）では「ソフトウェア開発ベンチマーク DeepSWE で 80% を叩き出した」と話題になりました。しかしこれは 10問のみの抜粋テストによる数値でした。

Cohere のヘンリー・チャン氏が全 113問でフルテストを実施したところ、スコアは **58.4%** でした。

| モデル | DeepSWE スコア（目安） | 料金 |
| :--- | :--- | :--- |
| **Claude Opus 5** | 約 74% | 有料 |
| **Ox Alpha** | **58.4%** | **無料** |
| **DeepSeek-V4-Pro** | 約 60% 前後 | 従量課金 |
| **Gemini 3.7 Flash** | 約 60% 前後 | 従量課金 |
| **Claude Opus 4.8** | 約 60% 前後 | 有料 |

最前線の最高峰モデル（Claude Opus 5 など）には一歩譲るものの、**Gemini 3.7 Flash や DeepSeek-V4-Pro、Claude Opus 4.8 に匹敵する推論性能を完全無料で使える**というのは、個人開発者やコストを抑えたい現場にとって驚異的な選択肢です。

## 4. Ox Alpha を利用する3つの方法（手順解説）

現在、**Ox Alpha** を利用する方法は主に3つあります。用途に合わせて選んでください。

### 方法1：Webチャット（oxalpha.com）で即座に試す（有志による無料提供）

最も手軽な方法です。アカウント登録もクレジットカードも不要で、ブラウザから直接思考モデルを試せます。

> ※ [oxalpha.com](https://oxalpha.com/) は開発元の公式サイトではなく、ファン・有志コミュニティによって無料提供されている独立プロジェクトです。

1. [https://oxalpha.com/chat](https://oxalpha.com/chat) にアクセスする。
2. チャット画面が開いたら、プロンプトを入力して送信する。
3. 思考プロセスが展開された後、回答がリアルタイムで生成される。

```
https://oxalpha.com/chat
```

UIはシンプルで動作も軽快。コードの断片レビューや設計相談、エラーログの解析などをサクッと試したいときに最適です。

---

### 方法2：OpenRouter 経由で API 呼び出し・各種ツール連携

プログラムからの呼び出しや、Cline・Cursor などの外部ツールと連携させたい場合は **OpenRouter** を経由します。

モデル ID は `stealth/ox-alpha` です。

#### 手順

1. [OpenRouter](https://openrouter.ai/) にログインし、API Keys ページでキーを発行する。
2. Python や Node.js の OpenAI 互換クライアントから呼び出す。

#### Python での実装例

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key="your_openrouter_api_key_here",
)

response = client.chat.completions.create(
    model="stealth/ox-alpha",
    messages=[
        {
            "role": "system",
            "content": "あなたは熟練のシニアソフトウェアエンジニアです。"
        },
        {
            "role": "user",
            "content": "Pythonで非同期キューを用いたワーカー処理の設計パターンと実装例を提示してください。"
        }
    ],
)

print(response.choices[0].message.content)
```

Claude Code、Clineなどの エージェントを使う場合も、プロバイダーを `OpenRouter` に設定し、モデル名に `stealth/ox-alpha` を指定するだけで連携完了です。

---

### 方法3：OpenCode / OpenCode Zen で使う

AI コーディング環境の **OpenCode**（および OpenCode Zen）では、すでに Ox Alpha が標準モデルリストに組み込まれており、無料で無制限に利用可能です。

![OpenCode での Ox Alpha Free 選択画面](https://raw.githubusercontent.com/lumichy/Qiita/main/public/ox-alpha-review-2026/opencode-zen.png)

1. OpenCode または OpenCode Zen のモデル選択画面を開く。
2. リスト先頭の **Ox Alpha Free (Unlimited)**（または `stealth/ox-alpha`）を選択する。
3. リポジトリをワークスペースに読み込ませ、エージェントモードで指示を出す。

OpenCode では全体の約 8% のシェアを獲得しており、ファイルの横断検索や自動コード生成、テスト実行のループをコストゼロで回すことが可能です。

## 5. 実際に使って分かったメリットと利用時の注意点

### メリット
- **長文コードへの耐性**: 複数ファイルにまたがる数十KBのコードを丸ごと貼り付けても、関数の依存関係を破綻させずに読み切ってくれる。
- **思考ログの納得感**: なぜそのリファクタリング方針を選んだのか、思考ステップが可視化されるためコードレビューの負担が減る。
- **圧倒的なコストパフォーマンス**: 現状はトークン課金ゼロ。実験的なプロトタイプ開発や重いログ解析で重宝する。

### 注意すべき制約・リスク
- **機密情報の送信は避ける**: 正体不明のステルスモデルであり、入力データがどのように学習・保管されているかの透明性は高くありません。本番の API キー、秘密鍵、社外秘ソースコードをそのまま流し込むのは避けてください。
- **無料提供は期間限定の可能性大**: ステルス検証期間が終了すれば、有料化またはモデル提供終了となる可能性が高いです。本番システムの固定依存先として組み込む際は注意が必要です。

## 6. まとめ

突如現れたステルスモデル **Ox Alpha** は、1M コンテキストと高い推論能力を備えた注目株です。

- **100万トークンのコンテキスト長**で大規模コードも丸ごと処理可能
- **DeepSWE スコア 58.4%** で Gemini 3.7 Flash や Claude Opus 4.8 級の実力
- **Webチャット（oxalpha.com/chat ※有志提供）**、**OpenRouter（stealth/ox-alpha）**、**OpenCode** から完全無料で利用可能
- ただし機密情報の取り扱いと期間限定の可能性には要注意

まずは [oxalpha.com/chat](https://oxalpha.com/chat) や OpenRouter で手元のコードを投げてみて、推論の切れ味を体感してみてください。
